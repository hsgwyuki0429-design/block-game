# SLIDE POP! ― ゲームデザインドキュメント

## 1. コンセプト

**「滑らせて、同色をぶつけて、盤面を空にする」**

広い盤面（最大12×12）。ブロックは押せば壁にぶつかるまで一直線に滑る。同じ色のブロック同士が触れれば弾けて消え、消えた跡には「空きマス」という通路が生まれる。重力も連鎖もない。あるのは**「空きマスこそが唯一の道具」**という事実だけ。盤面を完全に空にできたとき、あなたは最初から最後まで全てを読み切ったことになる――そんな、純度100%の空間推理パズルです。

盤面に置かれる色は**ちょうど2個ずつ**。ただし**その2個は、はじめから隣り合ってはくれない**。どのペアも「何手か滑らせて、やっと隣り合う」場所に置かれていて、**初期盤面ではどのブロックをどう動かしても1個も消えない**。

だから遊びの中身はこうなる ―― **「ここへ滑らせると、次にどこへ滑れるようになるか」を、消去にたどり着くまで頭の中で辿る。** スライドにスライドを重ねて、ぶつけたい場所まで運ぶ。目の前に「消える手」が無いからこそ、読むしかない。

## 2. ゲーム概要

| 項目 | 内容 |
|---|---|
| ジャンル | 空間パズル（スライド×接触消去） |
| 盤面 | 7×7 〜 12×12グリッド（レベルで拡大） |
| ブロック | テトロミノ7種（I・O・T・S・Z・L・J）、全回転。**この形だけ** |
| カラー | 3〜9色。色そのものは番号から手続き的に作るので上限なし |
| 同色の数 | **ちょうど2個ずつ**（色数×2 = 盤面のブロック数） |
| 初期配置 | 盤面の 46〜53%。**追い込みに必要な「滑走路」を残す** |
| 初期条件 | 同じ色同士は一切隣接していない／**初手に消せる手がひとつも無い**／必ず全消し可能 |
| 1プレイ | 14〜81手（PAR = 色数 + 追い込み手 + 仕込み手） |
| 進行 | レベル1から無限。同じレベルはどの端末でも同じ譜面。**鍵は無く、どのレベルにもいつでも入れる** |
| 評価 | **解決時間**による星3段階（目安以内／その2倍以内／クリア） |
| 情報 | 完全情報・初期配置以降ランダムなし |

### レベル進行

| 変わるもの | 進み方 |
|---|---|
| 色数 | L1で3色。3レベルごとに1色ずつ増え、**L19で9色（上限）** |
| ブロック数 | 色数×2。L19以降は18個 |
| 盤面 | 色数から決まる（1色あたり8マス、目標の埋め率50%）。L1で7×7、**L19で12×12（上限）** |
| 追い込み | 1組を消すまでに重ねるスライドの深さ。**L1で3手**、3レベルごとに深くなり **L16で8手（上限）**。総数は42手で頭打ち |
| 仕込み手 | **L5から**1手ずつ増え、**L27で12手（上限）** |

入門レベルにも「1手ずらせば届く」形は置いていない。見つけて押すだけで終わってしまい、読む余地が生まれないからだ。**L1でも1組にたどり着くまで3手**、上のレベルでは8手ぶん重ねる。

難しさはブロックの形ではなく、**色数・追い込みの深さ・仕込み手**でつける。形を複雑にすると「どこまでが1つの塊か」を読む負荷が増えるだけで、盤面のトポロジーを読む面白さは増えないと判断した。

色数の上限が9なのは盤面の広さの帰結。9色 = 18ブロック = 72マスで最大盤面12×12のちょうど50%。**追い込み手はブロックが滑る「滑走路」を必要とする**ので、以前（11色・埋め率62%）より意図的に空きを広げた。詰めるほど難しくなるわけではない ―― 動かせないだけで、深い読みは生まれない。

### 用語の定義

- **ブロック（ピース）**：テトロミノ1個ぶん（4セル）の剛体。移動・消去の最小単位
- **ペア**：同じ色のブロック2個。盤面にはこのペアが色数ぶん置かれる
- **追い込み手**：ペアの一方を「ぶつけられる場所」まで運ぶ、何も消さない手。1組を消すのに何手重ねるかが**追い込みの深さ**
- **仕込み手**：消したいブロックとは関係のないブロックを先に退かす、何も消さない手。通さないと後の手が成立しない
- **一本道**：どの局面でも「消せる手」の結果が実質1通りしかない状態（生成器のオプションとして残置。レベル定義では使っていない）
- **セル（マス）**：盤面の1区画
- **スライド**：ブロックが上下左右のいずれかに、障害物にぶつかるまで一直線に移動すること
- **接触**：異なるブロックのセルが上下左右で隣り合うこと（斜めは含まない）
- **グループ**：接触によって繋がった同色ブロックの集合
- **通路**：消去によって生まれた空きマス。以降のスライドが通過できる空間

## 3. ルールの三本柱

### ① スライド ― 「距離は選べない」

プレイヤーができる操作は**「どのブロックを、どの方向に押すか」**の二択だけです。押されたブロックは、壁か他のブロックにぶつかるまで滑り続けます。1マスで止めることも、手前で止めることもできません。

この**「距離の制御不能性」**が設計の要です。

- 全ての手が**決定的**になる。運も隠し情報もない
- 「押す前に、どこで止まるかを読む」ことがそのままゲームになる
- 1手1手の結果が盤面全体に波及するため、読みが深い

スライドはブロック単位（剛体）で行われます。I字型が縦に滑るとき、4セルすべてが同時に移動し、いずれか1セルでも障害物に触れれば全体が止まります。自分の元いたセルは通過可能です（自分が退いた後なので）。

### ② 同色接触消去 ― 「触れた瞬間、全部消える」

ブロックが滑り終えた直後、盤面全体が走査されます。上下左右で同じ色のブロックが触れ合っていれば、**その2個が即座に消去**されます。列を揃える必要はありません。色が触れれば、それで終わりです。

重要な細則として、**消去の単位は「ブロック」であり、単体のブロックは自己消去しません**。テトロミノは4セルすべてが同色ですが、それは「1つの塊」として扱われます。消去が発生するのは、**2つのブロックが接触したとき**だけです。この一点が、ゲームの成立そのものを支えています（セル単位なら初期盤面が瞬時に全滅するため）。

同じ色は盤面にちょうど2個しかないので、消去は常に**8セルちょうど**。そして重要なのは、**消去の結果が「どの色を消したか」だけで決まる**ことです。この性質が、後述する「一本道」を可能にします。

### ③ 重力なし ― 「空きマスは、あなたが稼ぐ」

消去されても、他のブロックは落下しません。すべてがその場にとどまります。

これは単なる「仕様の省略」ではなく、**ゲームの核心そのもの**です。重力がないということは：

- 消去は「プレイヤーが接触させた瞬間」にしか起きない（自動連鎖ゼロ）
- 空きマスは自然に生まれない。**消去して初めて生まれる**
- 生まれた空きマスは、以降のスライドの「通路」として機能する

つまり盤面は**「最初はほぼ壁」**です。最初の数手は短いスライドしかできません。しかし1つ消すごとに通路が開け、滑れる距離が伸び、選択肢が広がっていく。**盤面が、あなたの行為によって徐々に「解けて」いく**。この「空間を切り開いていく感覚」こそが、重力型パズルにはない本作固有の手触りです。

## 4. 勝敗条件と評価

- **勝利**：盤面からすべてのブロックをなくす（0個にする）
- **敗北条件は無い**

初期の設計には「どう動かしても同色接触を作れない＝デッドロック」という敗北条件がありました。これは**廃止しています**。追い込みを入れた今の設計では、**消せる手が無いのが通常の局面**です（どのレベルも初手はゼロ）。「いま消せない」ことは詰みではなく、**通路を作るところから始めろという合図**。敗北を宣言する代わりに、`戻す`と`やり直す`をいつでも使えるようにしています。

### 星 ― 解決時間で決まる

| 星 | 条件 |
|---|---|
| ★★★ | **目安の時間以内** |
| ★★ | その**2倍**まで |
| ★ | クリア |

目安は `20 + PAR×9 + 色数×4` 秒。L1で2:56、L30で12:00前後です。ゲーム画面のタイムは★★★を過ぎると黄、★★も過ぎると赤に変わり、**いま星いくつぶんの位置にいるか**が常に分かります。

**なぜ手数ではなく時間なのか。** 手数で測ると「詰まって戻す」ことが罰になります。すると**頭の中で試すより盤上で試したほうが損**という妙な圧力がかかり、`戻す`が使いにくくなる ―― 本来いちばんフェアな道具なのに。このゲームで時間がかかるのは指が遅いからではなく、盤面を読んでいるからです。時間で測れば `戻す` も `やり直す` も自由に使えて、それでも「読み切ってから指した人」がいちばん速い。**測りたいものを、そのまま測る。**

時計はゲーム画面を見ている間だけ進みます ―― ルールや設定のシートを開くと止まり、タブを離れても止まる。**ヒントは1回 +20秒**：星を丸ごと奪うのではなく、少しだけ重くする。詰まった人が先へ進めることのほうが大事なので、禁止も減点もしません。`やり直す`を押すと時計も0に戻り、**同じ盤面を「読み切ってから指す」挑戦**として遊び直せます。

星と自己ベストタイムはレベルごとに最高記録だけが残り、レベル一覧に並びます。

### 鍵は無い ― どのレベルにも、いつでも入れる

レベルに開放条件はありません。L1から順に上がってもいいし、いきなりL50を開いてもいい。

**理由は「詰まったプレイヤーに逃げ場が要る」から。** 本作は1問が長く（PARは14〜81手）、読み違えると手が止まります。そこで唯一の道が「同じ問題をもう一度」しか無いと、そこでゲームが終わってしまう。どのレベルも独立した1問で、順番に意味はない ―― 別のレベルを触ってから戻ると、たいてい見えていなかった線が見えます。

保存するのは**到達レベル（まだクリアしていない、いちばん手前のレベル）**と、レベルごとの星・自己ベストタイムだけ。到達レベルは鍵ではなく、「つづきから」の行き先と、レベル一覧でいまいる場所を示すためだけに使います。

## 5. 面白さの正体

### 5-1. 二重の意味を持つ「空きマス」

空きマスは同時に二つの役割を持ちます。

1. **通路**：ブロックが通過できる空間
2. **停止位置の定義**：ブロックは「空きマスが尽きた場所」で止まる

消去は盤面の**トポロジーそのものを書き換えます**。1つ消えることで、それまで届かなかった場所へ届くようになり、それまで止まっていた位置が意味を失う。**「どの順番で消すか」が「何を消せるか」を決める**。ここに本作の戦略の深さがあります。

### 5-2. 状態空間が「色の集合」に潰れる

同じ色が2個ずつしか無いので、1手の消去は**その色のペアを取り除くだけ**です。他のブロックは1マスも動きません。つまり：

> **消去後の盤面は「どの色を消したか」だけで決まる。**

この単純さのおかげで、生成器は「消せる色が何色あるか」だけを見て盤面の難しさを制御できます。**消せる色を0に保つことが、そのまま「読まないと1手も進めない盤面」になる。**

### 5-3. 追い込み ― スライドに、スライドを重ねる

本作の核。同じ色の2個は、**はじめから「ぶつけられる場所」には置かれません**。ペアを消すには、片方（あるいは両方）を何手か滑らせて、ようやく隣り合わせる必要があります。

ここで効いてくるのがルール①です。**滑って止まった直後は、同じ方向へはもう進めない**（壁か他のブロックがそこにあるから止まったのだから）。したがって**ブロックの道のりは必ずどこかで曲がる**。「右へ、それから下へ、それから左へ」――この折れ線を、盤上ではなく頭の中で辿ることになります。

しかも1手滑らせるたびに、そのブロック自身が**他のブロックにとっての新しい壁**になる。追い込みの道のりは互いに干渉し、**どのペアをどの順で追い込むか**という上位の問いに繋がっていきます。

初期盤面に消せる手をひとつも残さないのは、この体験を**最初の1手から**始めさせるためです。目の前に「消える手」があると、人はまずそれを押してしまう。押せる手が無ければ、読むしかない。

### 5-4. 仕込み手 ― 一見関係ないところを動かす

追い込みが「消したいブロック自身を動かす手」なのに対して、仕込み手は**まったく別のブロックを先に退かす手**です。

その手自体は何の見返りもありません。消去も演出も起きない。それでも通さないと、以降の手がひとつも成立しない ―― **「なぜここを動かすのか」が、動かした後にしか分からない**。追い込みが「このブロックをどう運ぶか」を問うのに対し、仕込み手は**「そもそも盤面のどこを触ればよいのか」**を問います。

### 5-5. プレイヤーの思考ループ

1. **走査**：盤面の同色ペアを見つける
2. **追跡**：その2個をぶつけるには、どちらをどの方向へ滑らせる？ どこで止まる？
3. **追い込み**：1手で届かないなら、2手なら？ 3手なら？ どこで曲がる？
4. **順序**：その通路を開けるには、先に何を消すべき？
5. **迂回**：どのペアもぶつけられないなら、何をずらせば道が変わる？（＝仕込み手）
6. **実行**：消去 → 新たな通路 → 再走査

この「目的から逆算して通路を確保する」**再帰的な計画**が、本作の知的快感の中核です。追い込みは、この再帰をブロック1個の中にも作りました ―― **ぶつける場所へ行くために、その手前へ行く必要がある。**

## 6. パズル生成 ― 「解ける盤面」を構造的に保証する

「ランダムに埋めて、解けるか検証する」という素朴な方法は使いません。高密度の盤面はほとんど解けず、検証コストも爆発するためです。代わりに**「解の逆順構築」**を採用しています。

### 発想の転換

盤面を作って解くのではなく、**解を作って盤面を導く**。完成状態（空盤面）から出発し、「ある1手でまとめて消えるブロック群」を1ステップずつ置いていきます。最後に置いたステップが、解の第1手になります。

### 各ステップで置くもの

**色cを新しく1つ選び、テトロミノを2個置く。**

- **移動ブロックP**：着地点B・滑走方向d・開始点A（= B − t×d）
- **相棒ブロックQ**：同色c。Bに居るPに隣接する

### 配置時に課す制約（それぞれが一つの保証に対応）

| 制約 | 保証する性質 |
|---|---|
| 新規セルはすべて空きマス | ブロックの重複なし |
| A→Bの経路が空、B+dに壁かブロック（ストッパー） | その手が実際に実行可能で、ちょうどBで止まる |
| Aに居るPはQに触れていない | 初期盤面から同色は隣接しない |

色ごとにブロックは2個しかないので、**「予定外の巻き込み消去」は原理的に起きません**。以前は「既存の同色ブロックと隣接しない」という制約でこれを防いでいましたが、いまは設計そのものが保証しています。

### 追い込み手 ― 同じ仕掛けを、逆向きに重ねる（3段構え）

ペアを置いただけでは「1手でぶつかる」盤面にしかなりません。そこで**巻き戻し**を重ねます。

置いたばかりのブロックを、**「滑らせればちょうど今の位置に来る」手前の位置A'へ戻す**。A'の条件は2つだけ ―― 今の位置の進行方向側に壁かブロックがあること（そこで止まる）、A'までの経路が空いていること。加えて **A'で相棒に触れていない**ことを課すので、その手自体では何も消えません。

n回巻き戻せば、その1組を消すのに**n+1手**が必要になります。

**巻き戻す相手は、ぶつけに行く側Pでも、待ち受ける側Qでもかまいません。** Qを巻き戻すと、プレイでは「先にQを定位置へ滑らせてから、Pをぶつける」ことになる ―― 1組を消すのに両方のブロックを動かす、いちばん読み応えのある形です。Qが戻る手はプレイ順で必ずPの消去手より前に来るので、**ストッパーは崩れません**（逆順構築の一貫性がそのまま効いています）。

候補の選び方が難易度を決めます。最優先は「**戻したあと、その色がもう1手では消せなくなっていること**」。これが満たされる限り、消すには必ずもう1手ぶん滑らせる必要があります。次に、長く滑る候補を好みます（盤面の端から端まで動くほど、読む範囲が広がる）。

**同じ局面へ戻る手は採りません。** 「右へ押して、左へ押し戻す」だけの往復は、放っておくと手順に混ざります（往復すると盤面が元に戻るので、ヒント用の局面テーブルでも衝突する）。作った各手の直前の局面を指紋で覚えておき、既に通った局面を作る候補は外します。

**深さは2段階で稼ぎます。** 逆順構築では、最初に置くペアほど「まだ何も無い盤面」で巻き戻すことになる。止まる先が壁しか無いので、そこで稼げる深さには限りがあります。ところが全部置き終えた盤面には**ストッパーが増えている** ―― さっきは戻せなかったブロックも、いまならもう1手ぶん戻せる。そこで、全ペアを置き終えたあとにもう一度巻き戻しの機会を配ります。

ここで足した手はプレイ順では前に来るので、「先にこれを動かしておかないと、あとでぶつけに行けない」という形になります。**ペアごとの道のりが互いに割り込み、1組ずつ順番に片づける解き方ができなくなる** ―― これが上のレベルの手応えの正体です。

### 仕込み手と、初手の押し戻し

- **仕込み手**：同じ巻き戻しを、**対象を選ばずに**行う。候補を列挙し、**動かした結果いちばん消せる色が減るもの**を選ぶ（0になればその手は必須になる）
- **初手の押し戻し**：「いきなり消せる色」が残っていたら奥へ追い込む。判定は**必ず盤面全体の「消せる色の数」で**行う ―― 当の色のブロックを動かすと、動かした先が別の色のストッパーになって、そちらが開いてしまうことがあるため。減らない手も一定回数までは許す（「1手では減らないが、動かせば次の1手で減らせる」形があるので、横ばいを禁じると手前で行き詰まる）。この掃除は**ペアを1組置くたびにも軽く走らせる** ―― 全部置き終えてからまとめて塞ごうとしても、巻き戻せる場所を使い切っていて動かす余地が残っていない
- **一本道**：生成器のオプションとして残置。追い込みが入った盤面ではそもそも大半の局面で消せる色が0なので、**レベル定義からは外しました**

狙いは **clearAtStart === 0**、すなわち「初期盤面では何をどう動かしても消えない」。実測ではレベル1〜80で **79/80** が達成、追い込みの目標手数も 79/80 で達成。成立しなかった性質があっても、**解けること自体は変わらず保証されます**。

### なぜ「不変条件」が効くか

どの手の直後も「同色ブロック同士は隣接していない」状態が保たれます（触れた瞬間に消えるため）。この不変条件があるからこそ、**「動かしたブロックが触れた相手だけが消える」**ことが確定し、逆順構築の各ステップが独立に検証可能になります。

この方式の副産物として、**PAR（保証解の手数）とヒントがほぼ無償で手に入ります**。解そのものがデータとして存在するからです。

ただしヒントには追加の仕掛けが要りました。追い込みが入った盤面では「いま消せる手」はたいてい存在しないので、**保証解の道筋から外れた瞬間にヒントが黙ってしまう**。そこで道筋を外れたときは、局面を指紋で重複除去しながら**幅優先で3手先まで探索し、消去にたどり着く道筋の1手目**を返します（ノード数に上限を置き、押した指が待たされないようにしています）。

> 実装上の補足：探索は「着地点B」ではなく「開始点A」から始めています。盤面に残るのはAに置いたブロックなので、壁や既存ブロックに接した配置（＝詰まった場所）から順に試すと空きマスが断片化せず、密度を稼げます。

## 7. 操作とフィードバック

### 操作体系

- **スワイプ**：ブロック上で上下左右にドラッグ。26pxの閾値を超えた瞬間に発動
- **着地予測ゴースト**：ドラッグ中、最終停止位置に半透明のゴーストと矢印を表示。「どこで止まるか」を可視化し、読みを助ける
- **クリック選択＋矢印キー**：精密操作・キーボード派向け
- **無効手**：動かせない方向へスワイプすると、ブロックが小刻みに揺れて拒否（手数に数えない）

### フィードバック設計 ― 文字は出さない

以前は「○個消し！」「◯コンボ」という浮き文字を出していました。**廃止しています。** 盤面の上に文字を置くと、いちばん見たいもの（次の一手）が隠れるうえ、読む時間だけテンポが落ちる。祝うのは**光と音**だけにして、連鎖の深さは音程・光の強さ・揺れの大きさが伝えます。

| 行為 | 反応 |
|---|---|
| スライド | easeOutCubicの加速→減速、残像トレイル、着地の小刻みな沈み込み |
| 消去 | マスが光に開く → 破片が散る → ネオンの輪が広がる → 一瞬白む → 画面が揺れる |
| 連鎖 | 音程が階段を上がり、光と揺れが 1 段ずつ強くなる（頭打ちあり。眩しすぎると読めない） |
| 3個以上まとめて消える | 直前に 0.1 秒だけ止める（タメ）。止めてから解放すると同じ演出でも強く感じる |
| 選択中 | 白く脈動するアウトライン |
| ヒント | 黄色の脈動＋方向矢印（何も消さない手なら「これ自体は何も消えません」、道筋なら「この手から数えて◯手で消せます」と伝える） |
| クリア | 星が1つずつ跳ねて出る |

### サウンド ― 乾いたウッドクリックと、砕けるガラス

音色は 2 種類しかありません。

- **ウッドクリック**：掴む・滑る・着地する・UI を押す ―― **操作すべて**。帯域を絞ったノイズの一撃（木を叩いた芯）＋ 上から落ちてくる基音（詰まった鳴り）＋ 4 倍音を少しだけ（マリンバの丸み）。全部これになることで、プレイがリズムになります
- **グラスシャター**：消えた瞬間だけ。非整数倍（`1, 2.41, 3.86, 5.62, 7.71, 9.94`）の部分音を少しずつ遅らせて散らす。整数倍だと「鐘」に、非整数倍だと「ガラス」に聴こえる

連鎖するとウッドクリックの音程がペンタトニックの階段を上がっていきます。**「次はもっと高い音を聴きたい」**という欲求が、そのまま次の一手を探す動機になります。ハプティクスは音を出す関数の中で一緒に鳴らすので、指と耳がずれません。

> 実装上の補足：iOS/Safari は WebAudio だけを鳴らしていると音声セッションが「環境音」扱いのままで、消音スイッチで黙るうえ、**画面収録しても動画が無音になります**。ほぼ無音の WAV を `<audio>` でループ再生し続けてセッションを「メディア再生」に上げ、同じセッションを共有する WebAudio の出力が収録に乗るようにしています。

### 見た目 ― 色だけを主役にする

ブロックには**影も光沢も模様も乗せません**。一色のベタ塗りに、ほんのわずかな角丸だけ。マス同士のすき間は1〜2pxしか空けないので、盤面はタイルを敷き詰めたモザイクのように見えます。

同じブロックのマス同士は継ぎ目なく繋がり、すき間が入るのは別のブロックとのあいだだけ。だから**「どこまでが一緒に動くか」は形で読めます**。後ろの盤面も同じ考えで、淡い色のマスを同じ寸法・同じすき間で敷き詰めただけの平らな面です。

ダークモードは持ちません。端末の設定に関わらず**ブロックの色が同じに見えること**を優先しています ―― 色そのものが情報である以上、配色が2種類あることは利点より欠点が大きいと判断しました。

盤面は画面幅の **90%** を占めます。左右の余白は詰め、進捗バーのような飾りは置かない。**視覚的なノイズを排除して、読むべきものを盤面だけにする**ためで、その結果として消えた瞬間の光がいちばん強く効きます。

### Liquid Glass ― 浮いている面だけがガラス

盤面はフラット、その上に浮く UI（ツールバー・シート・ボタン・チップ）だけが Z 軸の階層を作ります。ガラスの処方は全面で共通です。

- 背景を大きくぼかし、彩度を上げる（`blur(34px) saturate(200%)`）。後ろの色を吸って、ガラス自体がうっすら色づく
- 縁は 2 本 ―― 上端に白い光の線、全周に極薄の暗いヘアライン。白の上でも黒の上でも輪郭が消えない
- 上面の照り返しは要素の `background` に敷く。オーバーレイを重ねないので、文字の上に膜が乗らない

ホーム画面にだけ、ブロックの4色をごく淡く広げた光を敷いてあります。**ガラスは「後ろに何かある」ときにしか美しくならない**ためで、その上にガラスのボタンを置くと、背景の色を拾って縁が色づきます。

## 8. 難易度を構成する要素

- **追い込みの深さ**：1組を消すまでに重ねるスライドの数。**本作の主軸**。1手先ではなく n 手先の盤面を頭の中で作る必要がある
- **色数**：9色が混在する盤面から同色ペアを「見つける」負荷。追い込みの道のりが互いに干渉する数でもある
- **滑走距離**：長いスライドは長い通路を要求する
- **順序依存**：「Aを消さないとBへの通路が開かない」という依存関係の深さ
- **仕込み手**：**探すべきものが「消える手」でも「消したいブロック」でもない**。盤面のどこを触ればよいのか自体が問題になる
- **一本道**（生成器のオプション）：選択肢が1つしかないということは、**間違いに気づくのが遅れる**ということ

生成時のパラメータ（盤面サイズ、色数、追い込み手の総数、仕込み手の数、一本道を課すか、配置のランダム性）を調整することで、これらの要素をコントロールできます。レベルごとの値は `src/levels.js` の `levelConfig()` が、生成器側の既定値は `src/generator.js` の `DEFAULT_OPTIONS` が持っています。

「読みの深さ」を測る指標として、`npm run verify` は **最長の無消去連続**（保証解の中で何も消えない手が最大何手続くか）を出します。実測でレベル1〜80の平均32.3手、最大53手 ―― **53回スライドを重ねて、やっと1組**。

## 9. 位置づけと独自性

| ゲーム | 移動 | 消去 | 重力 |
|---|---|---|---|
| テトリス | 落下・回転 | ライン揃え | あり |
| ぷよぷよ | 落下 | 同色4連結 | あり（連鎖） |
| SameGame | クリック | 同色連結 | あり |
| Rush Hour | スライド | なし | なし |
| アイススライド系 | 決定論的スライド | なし | なし |
| **SLIDE POP!** | **決定論的スライド** | **同色ペア接触** | **なし** |

本作は**「アイススライドの決定論性」×「接触消去」×「重力なし（空間が資源）」**という、それぞれ実績のある mechanic の未踏の交差点に位置しています。特に「消去が通路を生み、通路が消去を可能にする」という**循環構造**は、重力型パズルにも純スライドパズルにも存在しない、本作固有のものです。

そのうえで本作は、**消去そのものを遠ざけました**。同色ペアは1手ではぶつからず、ぶつけに行く道のりを何手も組み立てる必要がある。結果として、アイススライド系の「1本の折れ線を読む」楽しさと、接触消去系の「盤面のトポロジーが書き換わる」楽しさが、1つの手番の中で重なります。

## 10. 拡張の方向性

- **デイリーパズル**：その日のレベルを全プレイヤー共通に・タイムのランキング
- **リプレイ共有**：解の手順をシリアル化して共有・検証可能に
- **追い込みの可視化**：ヒントを「1手目」ではなく折れ線そのもので見せるモード（初級者向けの補助輪）
- **実装済み**：ステージ制（レベル1から無限。盤面・色数・追い込みの深さ・仕込み手が段階的に厳しくなる）、レベル固定シードによる全端末共通の譜面、**鍵の無いレベル選択**、**解決時間による星評価と自己ベスト**

---

**総括**：SLIDE POP!は「空きマスという負の空間を、消去によって稼ぎ、滑走によって消費する」ゲームです。ルールは3つしかないのに、盤面のトポロジーが手ごとに書き換わることで、深い再帰的計画が生まれます。

そして**同色ペアは、はじめから隣り合ってはくれない**。初手からすでに、目の前に押せる手はありません。スライドにスライドを重ねて、ぶつける場所まで運ぶ道筋を、頭の中で組み立てるしかない。星が手数ではなく時間で決まるのは、**測りたいものがまさにその「読んでいた時間」だから**です。

生成アルゴリズムが「解けること」を構造的に保証するため、プレイヤーは常に「自分が悪かった」と納得できる――純粋パズルとして最も大切な信頼関係を、設計の土台から持っているゲームです。
