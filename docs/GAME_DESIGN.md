# SLIDE POP! ― ゲームデザインドキュメント

## 1. コンセプト

**「凍った盤面を滑らせて、同色をぶつけて、盤面を空にする」**

ほぼ埋め尽くされた12×12の盤面。ブロックは押せば壁にぶつかるまで一直線に滑る。同じ色のブロック同士が触れれば弾けて消え、消えた跡には「空きマス」という通路が生まれる。重力も連鎖もない。あるのは**「空きマスこそが唯一の道具」**という事実だけ。盤面を完全に空にできたとき、あなたは最初から最後まで全てを読み切ったことになる――そんな、純度100%の空間推理パズルです。

---

## 2. ゲーム概要

| 項目 | 内容 |
|---|---|
| ジャンル | 空間パズル（スライド×接触消去） |
| 盤面 | 12×12グリッド |
| ブロック | テトロミノ7種（I・O・T・S・Z・L・J）、全回転 |
| カラー | 6色（赤・橙・黄・緑・青・紫） |
| 初期配置 | 盤面の約80%（116〜120マス）を埋め尽くし |
| 初期条件 | 同じ色同士は一切隣接していない／必ず全消し可能 |
| 1プレイ | 約10〜15手（PAR=保証解の手数） |
| 情報 | 完全情報・初期配置以降ランダムなし |

### 用語の定義

- **ブロック（ピース）**：1〜4セルで構成される剛体。移動・消去の最小単位
- **セル（マス）**：盤面の1区画
- **スライド**：ブロックが上下左右のいずれかに、障害物にぶつかるまで一直線に移動すること
- **接触**：異なるブロックのセルが上下左右で隣り合うこと（斜めは含まない）
- **グループ**：接触によって繋がった同色ブロックの集合
- **通路**：消去によって生まれた空きマス。以降のスライドが通過できる空間

---

## 3. ルールの三本柱

### ① スライド ― 「距離は選べない」

プレイヤーができる操作は**「どのブロックを、どの方向に押すか」**の二択だけです。押されたブロックは、壁か他のブロックにぶつかるまで滑り続けます。1マスで止めることも、手前で止めることもできません。

この**「距離の制御不能性」**が設計の要です。

- 全ての手が**決定的**になる。運も隠し情報もない
- 「押す前に、どこで止まるかを読む」ことがそのままゲームになる
- 1手1手の結果が盤面全体に波及するため、読みが深い

スライドはブロック単位（剛体）で行われます。I字型が縦に滑るとき、4セルすべてが同時に移動し、いずれか1セルでも障害物に触れれば全体が止まります。自分の元いたセルは通過可能です（自分が退いた後なので）。

### ② 同色接触消去 ― 「触れた瞬間、全部消える」

ブロックが滑り終えた直後、盤面全体が走査されます。上下左右で同じ色のブロックが触れ合っていれば、**繋がったグループ全体が即座に消去**されます。列を揃える必要はありません。色が触れれば、それで終わりです。

重要な細則として、**消去の単位は「ブロック」であり、単体のブロックは自己消去しません**。テトロミノは4セルすべてが同色ですが、それは「1つの塊」として扱われます。消去が発生するのは、**2つ以上のブロックが接触したとき**だけです。この一点が、ゲームの成立そのものを支えています（セル単位なら初期盤面が瞬時に全滅するため）。

消去は常に**8セル以上**（ブロック2個分）がまとめて消えます。この「まとまって消える感触」が、本作の手応えの源です。

### ③ 重力なし ― 「空きマスは、あなたが稼ぐ」

消去されても、他のブロックは落下しません。すべてがその場にとどまります。

これは単なる「仕様の省略」ではなく、**ゲームの核心そのもの**です。重力がないということは：

- 消去は「プレイヤーが接触させた瞬間」にしか起きない（自動連鎖ゼロ）
- 空きマスは自然に生まれない。**消去して初めて生まれる**
- 生まれた空きマスは、以降のスライドの「通路」として機能する

つまり盤面は**「最初はほぼ壁」**です。最初の数手は短いスライドしかできません。しかし1つ消すごとに通路が開け、滑れる距離が伸び、選択肢が広がっていく。**盤面が、あなたの行為によって徐々に「解けて」いく**。この「空間を切り開いていく感覚」こそが、重力型パズルにはない本作固有の手触りです。

## 4. 勝敗条件

- **勝利**：盤面からすべてのブロックをなくす（0個にする）
- **敗北**：どのブロックをどの方向に動かしても同色接触が発生しない「デッドロック」状態

敗北判定は全ブロック×4方向の総当たりシミュレーションで行われます。スライドは決定的なので、これは完全に判定可能です。「詰み」は運ではなく、それまでの手順の帰結として訪れます。だからこそ**一手戻す（Undo）が常にフェア**です。

> 実装上の補足：「消去しない手が通路をずらし、その次の手で消去が可能になる」ケースを誤って敗北と判定しないため、実装では消去手が2手以内にひとつも存在しないときだけデッドロックとしています（仕様より緩い＝プレイヤーに有利な方向）。

## 5. 面白さの正体

### 5-1. 二重の意味を持つ「空きマス」

空きマスは同時に二つの役割を持ちます。

1. **通路**：ブロックが通過できる空間
2. **停止位置の定義**：ブロックは「空きマスが尽きた場所」で止まる

消去は盤面の**トポロジーそのものを書き換えます**。1つ消えることで、それまで届かなかった場所へ届くようになり、それまで止まっていた位置が意味を失う。**「どの順番で消すか」が「何を消せるか」を決める**。ここに本作の戦略の深さがあります。

### 5-2. 橋渡し（ブリッジ）― 最大の快感

最も気持ちの良い手は、**離れた2つの同色グループの間にブロックを滑り込ませ、3つを一度に繋いで消す手**です。

```
消去前：  [赤A]  …空き…  [赤B]  …空き…  [赤C]
          （互いに離れていて、どれも単体では消えない）

赤Bを滑らせて AとCの両方に接触させると――
          [赤A][赤B][赤C] が一瞬で繋がり、全部消える
```

ルール上、消去されるグループは**必ず「動かしたブロック」を経由して繋がります**（動かしていないブロック同士は既に非隣接が保証されているため）。つまり動くブロックは常に「ハブ」になる。この**星型構造**を理解した瞬間、盤面の見え方が変わります。

### 5-3. プレイヤーの思考ループ

1. **走査**：盤面の同色ペア・グループを見つける
2. **追跡**：それを繋ぐには、どのブロックをどちらへ滑らせる？ どこで止まる？
3. **順序**：その通路を開けるには、先に何を消すべき？
4. **実行**：消去 → 新たな通路 → 再走査

この「目的から逆算して通路を確保する」**再帰的な計画**が、本作の知的快感の中核です。

## 6. パズル生成 ― 「解ける盤面」を構造的に保証する

「ランダムに埋めて、解けるか検証する」という素朴な方法は使いません。80%埋めの盤面はほぼ確実にデッドロックを含み、検証コストも爆発するためです。代わりに**「解の逆順構築」**を採用しています。

### 発想の転換

盤面を作って解くのではなく、**解を作って盤面を導く**。完成状態（空盤面）から出発し、「ある1手でまとめて消えるブロック群」を1ステップずつ置いていきます。最後に置いたステップが、解の第1手になります。

### 各ステップで置くもの

- **移動ブロックP**：色c・形状・着地点B・滑走方向d・開始点A（= B − t×d）
- **相棒ブロックQ₁..Qₘ**：同色c。それぞれBのPに隣接し、Q同士は非隣接

### 配置時に課す制約（それぞれが一つの保証に対応）

| 制約 | 保証する性質 |
|---|---|
| 新規セルはすべて空きマス | ブロックの重複なし |
| 既存の同色ブロックと隣接しない | 初期盤面の同色隣接ゼロ ＋ 解の各手で「予定外の巻き込み消去」が起きない |
| A→Bの経路が空、B+dに壁かブロック（ストッパー） | その手が実際に実行可能で、ちょうどBで止まる |
| Aに居る時点で同色接触していない | 中間状態の不変条件（どの手の直後も同色非隣接）が保たれる |

### なぜ「不変条件」が効くか

どの手の直後も「同色ブロック同士は隣接していない」状態が保たれます（触れた瞬間に消えるため）。この不変条件があるからこそ、**「動かしたブロックが触れた相手だけが消える」**ことが確定し、逆順構築の各ステップが独立に検証可能になります。

この方式の副産物として、**PAR（保証解の手数）とヒント機能がほぼ無償で手に入ります**。解そのものがデータとして存在するからです。

> 実装上の補足：探索は「着地点B」ではなく「開始点A」から始めています。盤面に残るのはAに置いたブロックなので、壁や既存ブロックに接した配置（＝詰まった場所）から順に試すと空きマスが断片化せず、埋め率が74%から81%まで上がりました。色は使用数の少ないものを優先し、6色がまんべんなく盤面に出るようにしています。

## 7. 操作とフィードバック

### 操作体系

- **スワイプ**：ブロック上で上下左右にドラッグ。26pxの閾値を超えた瞬間に発動
- **着地予測ゴースト**：ドラッグ中、最終停止位置に半透明のゴーストと矢印を表示。「どこで止まるか」を可視化し、読みを助ける
- **クリック選択＋矢印キー**：精密操作・キーボード派向け
- **無効手**：動かせない方向へスワイプすると、ブロックが小刻みに揺れて拒否（手数に数えない）

### フィードバック設計

| 行為 | 反応 |
|---|---|
| スライド | easeOutCubicの加速→減速、残像トレイル、着地の小刻みな沈み込み |
| 消去 | 破裂パーティクル、拡散リング、画面シェイク（消去数に比例） |
| 大量消去 | 「○個消し！」の浮き文字＋段階評価（12個=グレイト、16個=ファンタスティック、20個=ミラクル） |
| 選択中 | 白く脈動するアウトライン |
| ヒント | 黄色の脈動＋方向矢印 |

大量消去の段階評価は、**「うまい手ほど派手に褒める」**という設計です。橋渡しを見つけて実行した瞬間が、最も強く報われます。

## 8. 難易度を構成する要素

- **滑走距離**：長いスライドは長い通路を要求する
- **1手のピース数**：2個消しは素直、3〜4個の橋渡しは発見が難しい
- **順序依存**：「Aを消さないとBへの通路が開かない」という依存関係の深さ
- **視覚的ノイズ**：6色が混在する盤面から同色ペアを「見つける」負荷

生成時のパラメータ（1ステップのピース数、配置のランダム性）を調整することで、これらの要素をコントロールできます。`src/generator.js` の `DEFAULT_OPTIONS` が該当します。

## 9. 位置づけと独自性

| ゲーム | 移動 | 消去 | 重力 |
|---|---|---|---|
| テトリス | 落下・回転 | ライン揃え | あり |
| ぷよぷよ | 落下 | 同色4連結 | あり（連鎖） |
| SameGame | クリック | 同色連結 | あり |
| Rush Hour | スライド | なし | なし |
| アイススライド系 | 決定論的スライド | なし | なし |
| **SLIDE POP!** | **決定論的スライド** | **同色接触** | **なし** |

本作は**「アイススライドの決定論性」×「接触消去」×「重力なし（空間が資源）」**という、それぞれ実績のある mechanic の未踏の交差点に位置しています。特に「消去が通路を生み、通路が消去を可能にする」という**循環構造**は、重力型パズルにも純スライドパズルにも存在しない、本作固有のものです。

---

## 10. 拡張の方向性

- **手数制限モード**：PAR+N手を上限にしたタイムアタック的緊張
- **色数調整**：5色に絞って同色密度を上げ、橋渡しを増やす高難度化
- **デイリーパズル**：シード固定で全プレイヤー同一盤面・ランキング（シード固定と `#daily` は実装済み）
- **ステージ制**：序盤は2色・狭い盤面から、段階的に要素を導入
- **リプレイ共有**：解の手順をシリアル化して共有・検証可能に

---

**総括**：SLIDE POP!は「空きマスという負の空間を、消去によって稼ぎ、滑走によって消費する」ゲームです。ルールは3つしかないのに、盤面のトポロジーが手ごとに書き換わることで、深い再帰的計画が生まれます。そして生成アルゴリズムが「解けること」を構造的に保証するため、プレイヤーは常に「自分が悪かった」と納得できる――純粋パズルとして最も大切な信頼関係を、設計の土台から持っているゲームです。
